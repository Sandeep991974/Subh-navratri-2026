# Navratri Utsav — deployable website

A responsive, festive Navratri landing page built with plain HTML, CSS, and JavaScript. It uses the supplied Durga Maa and Garba artwork, styled with a saffron-and-green theme and updated with a 2026 greeting. No build step or framework required.

## Preview locally
1. Extract the project ZIP.
2. Open `index.html` in a modern browser.
3. For clipboard/share features, a local web server or hosted HTTPS site works best. You can use VS Code's Live Server extension if you have it.

## Publish free with Netlify Drop
1. Open **https://app.netlify.com/drop** in your browser.
2. Sign in or create a free Netlify account if asked.
3. Extract `navratri-special.zip` on your device.
4. Drag the extracted **`navratri-special` folder** (including `index.html`, `styles.css`, `script.js`, and the `assets` folder) onto the Netlify Drop page. If your browser/device does not allow folder drag-and-drop, try from a desktop browser.
5. Wait for Netlify to deploy the site. Netlify will show a public URL ending in `netlify.app`.
6. Open that URL in a new tab and test the buttons. Copy the URL and send it to friends on WhatsApp, Instagram, etc.
7. Optional: in the Netlify site dashboard, choose **Site configuration / Site details** (labels may change) to change the generated site name if your preferred name is available.

## Update the site later
Edit `index.html`, `styles.css`, or `script.js`, then upload the updated project folder again using Netlify Drop, or connect a Git repository for continuous deployment. Keep `assets/navratri-artwork.png` in the project so the Durga Maa and Garba banner loads.

## Notes
- The Hindi Navratri greeting plays only when a visitor clicks one of the “Please click” buttons; it never starts automatically. Voice availability and quality depend on the browser and installed system voices.
- Google Fonts are loaded online. The page still has fallback fonts if they are unavailable.
- The site is static and does not collect or store visitors' personal information.
- No public URL has been created by this project ZIP. You must complete the Netlify deployment steps above to receive your own live link.
